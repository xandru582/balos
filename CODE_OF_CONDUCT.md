# Code of Conduct

## The short version

Be decent. Assume good faith. Don't be a jerk.

## The slightly longer version

BalOS is a community project. We want contributors from every background to
feel safe and productive here. To that end:

**Do:**

- Treat others with respect, even when you disagree.
- Critique code, not people.
- Assume the other person means well until clearly shown otherwise.
- Give people time to respond — maintainers are volunteers.
- Admit when you're wrong. Learn out loud.

**Don't:**

- Harass, threaten, or discriminate against anyone for any reason.
- Dogpile. One dissent is a conversation; fifteen is a mob.
- Out anyone's personal info without consent.
- Use this project to promote hate speech, violence, or illegal activity.
- Treat "free speech" as a defense for incivility.

## Enforcement

Maintainers will remove comments, commits, or contributions that violate this
Code of Conduct. In serious or repeated cases, offenders will be banned from
the repository.

Report incidents to **xandru2222+balos-coc@gmail.com**. Reports are
confidential. We will not share your identity with the accused without your
explicit consent.

## Scope

This Code of Conduct applies to all project spaces — GitHub Issues, PRs,
Discussions, any official chat channels, and in-person events where you
represent BalOS.
